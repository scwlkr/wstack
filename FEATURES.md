# Feature Map

- **Wstack mode**: `$wstack` applies Shane's SDLC, shipping, environment, writing and maintenance guidance until switched off. It selects useful internal guides and external skills, and applies `tldraw-visual` when creating or editing tldraw files.
- **SDLC Guidance**: Restate the understood goal, then follow Plan, Design, Build, Test, Deploy and Maintain at appropriate depth. Stages can overlap while Shane can steer; approved live-site delivery includes deployment and a live check.
- **Design Router**: Select fitting interface-design guidance, starting with Impeccable and Taste Skill. Small changes may need no skill or light guidance; meaningful alternatives and deliberation scale to the work.
- **Fresh Code Review**: Every code change, including tiny edits and review fixes, receives adversarial review by a new agent that did not implement it and inherits no implementation conversation. Review checks the requested outcome, code and project standards.
- **Public and Private Maintenance**: Keep affected public docs, packages and website accurate, verify actual artifacts, and maintain private project context and the shared computer. Prefer resource reuse and clean owned disposable simulators, worktrees, tests and experiments after success or failure.
- **Install and Update**: Windows, macOS and Linux commands install latest Wstack globally for Codex, Cursor and Claude Code, replace old copies and remove confirmed retired Wstack skills. Preserves unrelated skills and project files.
- **Project Setup**: Quiet versioned setup creates `w.md` and a short agent pointer; adds a basic project CLI when needed. Reuses existing commands and preserves notes outside managed blocks; [documented setup limitations](docs/sdlc-current-state.md#project-setup) cover managed-block content and native Windows setup.
- **Feature Map**: Named features with short editable descriptions provide shared product vocabulary. Optional detail files grow with the work.
- **Writing, Design and Brand**: Concrete anti-slop guidance supports creation and editing; brand work delivers editable SVGs and type/color/voice/mockup guidance.
- **Suite Maintenance CLI**: `./project check`, `list`, `sync` and `ci` maintain the installed skill and run this repository's required checks.
