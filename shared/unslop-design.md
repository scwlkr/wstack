# Design

Creation + refinement → content/task/approved identity drive composition; preserve character and working behavior.
- Generic hero + stock dashboard → specific task/message + actual product view when useful.
- Cards around every related setting → one labeled group; independent actions/comparisons can stay cards.
- Competing filled buttons/highlights → clear primary action and hierarchy.
- Glows/gradients/glass/badges/icons → keep only roles in identity, recognition or understanding.
- Layout follows relationships: sequential steps → flow; comparisons → grid. No invented filler or forced asymmetry.
- Fake metrics/testimonials/screens → supplied evidence or remove; never invent proof.
- Oversized gaps → tighter related groups before smaller text; preserve reading/touch comfort.
- Static content looks static; actions look actionable. Preserve labels/contrast/keyboard/focus.
- Motion explains feedback/transitions; drop distracting entrances/bounces; respect reduced motion.
- Inspect actual result: desktop + half-desktop + phone; native-only → supported device sizes.
- Exercise affected controls/states with realistic long/empty/loading/error content.
- Review-only → findings; edit for concrete benefit. No aesthetic bans or forced plainness.
